Happy Birthday Card — Khadija

How to use

- Open `index.html` in a browser (double-click or `File → Open`).
- The initial welcome screen contains an "Open Your Surprise" button. Click it to reveal the birthday card.
- Music is intentionally deferred; the audio file is located at `music/birthday.wav` if you want to enable it locally.

Notes

- This is a simple static site (HTML/CSS/JS). No build steps required.
- Tested on modern desktop browsers. Mobile layout may need small adjustments.
